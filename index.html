Topik 1

Pengertian Sistem Komputer

Sistem Komputer adalah kumpulan elemen-elemen terintegrasi (perangkat keras, perangkat lunak, dan pengguna) yang saling berinteraksi untuk mengolah data sehingga menghasilkan informasi yang bermanfaat.

Ciri Utama Sistem Komputer:
  • Memiliki alur masukan (input) dan keluaran (output).
  • Bekerja secara otomatis berdasarkan instruksi yang diberikan.
  • Mampu menyimpan data untuk digunakan kembali.
Topik 2

Elemen Utama Sistem Komputer

Sistem komputer dibangun oleh 3 elemen saling melengkapi:

1

Hardware (Perangkat Keras)

Komponen fisik komputer yang dapat disentuh dan dilihat secara nyata. Contoh: Keyboard, Monitor, CPU.

2

Software (Perangkat Lunak)

Program atau instruksi tidak berwujud fisik yang menjalankan komputer. Contoh: Windows, Web Browser.

3

Brainware (Pengguna)

Manusia yang mengoperasikan, mengelola, dan memberi perintah pada sistem komputer. Contoh: Programmer, Siswa.

Topik 3

Pengertian & Fungsi Perangkat Keras

Perangkat Keras (Hardware) adalah seluruh peralatan elektronik fisik pada komputer.

Fungsi Utama Perangkat Keras:

  • Menerima data masukan dari pengguna (Input).
  • Mengolah instruksi dan perhitungan matematika/logika (Process).
  • Menyimpan data baik sementara maupun permanen (Storage).
  • Menampilkan atau menghasilkan informasi hasil olahan (Output).
Topik 4

Klasifikasi Perangkat Keras

Berdasarkan fungsinya, perangkat keras dibagi menjadi 4 kelompok utama:

1. Perangkat Input (Masukan)

Perangkat untuk memasukkan data/perintah ke dalam komputer.

Contoh: Keyboard, Mouse, Scanner, Microphone, Webcam.

2. Perangkat Process (Pemrosesan)

Perangkat yang mengolah data yang diterima dari perangkat input.

Contoh: Processor (CPU), RAM, VGA / Kartu Grafis.

3. Perangkat Storage (Penyimpanan)

Perangkat untuk menyimpan data dan program komputer.

Contoh: Harddisk, SSD, Flashdisk, MicroSD.

4. Perangkat Output (Keluaran)

Perangkat yang menyajikan hasil pemrosesan data kepada pengguna.

Contoh: Monitor, Printer, Speaker, Proyektor.

Topik 5

Alur Kerja IPO (Input - Process - Output)

Prinsip kerja komputer selalu mengikuti alur logis yang konsisten, yaitu Input → Process → Output, dengan dukungan perangkat Storage untuk menyimpan data.

1. INPUT Data mentah dimasukkan
2. PROCESS CPU mengolah data
3. OUTPUT Informasi ditampilkan
Topik 6

Peran Perangkat Keras dalam Sehari-hari

Berikut adalah contoh alur IPO pada penerapan dunia nyata:

Studi Kasus 1: Kasir Minimarket

Input: Barcode Scanner membaca kode produk.
Process: Komputer kasir mencari harga barang di database.
Output: Layar monitor menampilkan total belanja & Printer mencetak Struk Belanja.

Studi Kasus 2: Absensi Sidik Jari Sekolah

Input: Sensor Fingerprint membaca pola jari siswa.
Process: Mesin mencocokkan sidik jari dengan data siswa.
Output: Speaker berbunyi "Terima Kasih" & data kehadiran tersimpan di storage.

Rangkuman Inti Materi

  • Sistem Komputer: Kesatuan hardware, software, dan brainware yang bekerja bersama mengolah data menjadi informasi.
  • Hardware (Perangkat Keras): Komponen fisik yang diklasifikasikan menjadi 4 fungsi: Input, Process, Storage, dan Output.
  • Alur Kerja IPO: Data dimasukkan lewat perangkat Input → diolah oleh Process (CPU) → disajikan oleh Output → disimpan di Storage.
  • Penerapan Nyata: Penggunaan hardware sangat luas seperti pada Kasir Minimarket, Sensor Sidik Jari, dan Mesin ATM.
